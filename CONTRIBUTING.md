# Contributing

Thanks for contributing.

## Adding a Cheatsheet

Keep each cheatsheet focused on one topic.

Recommended structure:

```markdown
# Topic

> One-sentence definition.

## What Is It?

## Why Does It Matter?

## Core Concepts

## How It Works

## Common Confusions

## Practical Rules of Thumb

## Related Cheatsheets

## Further Reading
```

## Style

- Define acronyms on first use.
- Prefer short paragraphs.
- Use diagrams when they clarify architecture.
- Separate simplified mental models from technical details.
- Avoid unsupported product-specific claims.
- Prefer primary sources for implementation details.
- Keep links relative when linking within this repository.

## Accuracy

If a claim depends on a specific hardware generation, framework version, model release, or API, identify that scope explicitly.

AI changes quickly. Avoid presenting temporary implementation details as universal facts.
