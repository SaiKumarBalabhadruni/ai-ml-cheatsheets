# Generative AI Cheat Sheet

## Generative AI

Generative AI refers to systems that generate new content.

Examples:

- Text
- Code
- Images
- Audio
- Video
- 3D content

## Discriminative vs Generative

A simplified distinction:

**Discriminative:** predict or classify.

**Generative:** produce new samples or content.

## Common Generative Model Families

- Autoregressive Transformers
- Diffusion Models
- GANs
- VAEs
- Flow-based and related generative approaches

## Multimodal

A multimodal system can process or generate more than one modality.

Examples:

```text
Text + Image
Text + Audio
Image + Text
Video + Audio + Text
```

## Prompt

Instructions or input supplied to a generative model.

## Conditioning

Additional information used to guide generation.

## Sampling

The process of selecting outputs from a model's probability distribution.

Common controls include:

- Temperature
- Top-k
- Top-p

## Latent Space

A learned representation where complex data can be represented more compactly.

## Quality vs Control

Generative systems often balance:

- Fidelity
- Diversity
- Controllability
- Speed
- Cost
- Safety
